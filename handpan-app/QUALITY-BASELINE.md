## Sequence grid

The Sequence panel is a hands-on 4-voice × 16-step grid. Each row has a distinct synthesized timbre; tap cells to toggle notes. Patterns persist locally and are not auto-randomized during playback.

## Service worker

`CACHE_VERSION` is `pionier-v` + `handpan-app/APP_VERSION` (current shipping version: **pionier-v217** / **217**).
Shell list is generated by `npm run sync:handpan`. Verify with `npm run check:handpan-cache` before deploy.

## My Library

Looper compositions are stored in IndexedDB on this device, with playback and per-recording WAV export. Browser persistence is best-effort; clearing site data can erase recordings. Runtime browser and device behavior still needs verification.

## Soft failure

Boot states: `loading` → `ready` | `degraded` | `failed` via `#appStatus`. Optional modules fail soft.

## TonePad sequence

- Separate swipe-in ambient backing surface; the handpan remains the main screen.
- One shared AudioContext/master bus; sequence uses its own synthesis bus with adjustable output level.
- Scale-aware notes from the active handpan scale, with Density, Evolution, Space, Level, Freeze and Regenerate controls.
- Looper exposes master duration, phase, cycle and pause state for sequence synchronization.
- Browser smoke/regression coverage lives in `scripts/app-tests/phase11-ambient-sequencer.spec.mjs`.
- Runtime release gate: validate timing, level balance and gesture behavior on real iOS Safari before considering the feature production-ready.
