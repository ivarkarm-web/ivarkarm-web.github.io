# Pionier quality baseline

Measured against `origin/main` after UI layout + picker fixes (2026-10-16).

## Shell / layout

| Fact | Value |
|------|-------|
| Bottom bar order | looper → scale + base note → instrument + notes |
| Pan gap to bar | ~12px (`--pan-bottom-gap`) |
| Drop-downs | Body-portaled; `.picker-sheet` on phone/touch (≤900px / coarse / short viewport); `.picker-popover` on wide desktop; z-index 5200; solid background |
| Scale / instrument menus | Visible, scrollable bottom sheets; close on item select + Escape + backdrop |
| Loop button | 44–52px, not clipped |
| Scale labels | Readable names (`A Minor`, `E Amara`); compact `short` for the bar pill |

## Stylesheets linked from index

`pionier`, `welcome-screen`, `topbar-narrow`, `looper`, `scale-menu`, `settings-panel`, `atelier`, `ui-stability`, `fx-editor`, `focus-visible`  
Retired: `chrome-fix`, `ui-layout-extras`, `app.css`, `handpan.css`

## Service worker

`CACHE_VERSION` is `pionier-v` + `handpan-app/APP_VERSION`.
Shell list is generated by `npm run sync:handpan` from `index.html` + `pionier-app.js` stamps.
Verify with `npm run check:handpan-cache` before deploy. Network-first HTML; cache-first assets.

## Bedroom Sessions

8 archive.org MP3s; player markup present.

## Soft failure

Boot states: `loading` → `ready` | `degraded` | `failed` via `#appStatus`. Optional modules fail soft.

## Still not covered in CI

- Full offline proof
- Real-device iOS Safari
- axe-core / multi-pointer stress

## Boot / first paint (2026-10-22 phase 2)

Critical path: `pionier-core` + handpan scales + scale selector.
Deferred (idle or first use): looper, FX editor, arps, note-plus, soundscapes.
Audio unlock on Enter (`pionier:user-enter` + silent buffer + resume).

## Phase 3 resilience (2026-10-22)

- Soundscapes queue built with DOM textContent (no innerHTML).
- Network/offline status: clear “Needs network / check connection” on track load failure.
- Escape closes pickers, FX editor, FX panel, soundscapes; focus returns to opener.
- focus-visible on Enter, looper, scale, ♫, soundscape controls.
- Smoke checks offline-critical SW SHELL paths; Playwright `phase3-smoke.spec.mjs`.
