# Pionier quality climb plan (target: every category ≥ 8/10)

**Baseline:** overall 6.4/10 (C+). Measured facts captured in `docs/BASELINE-METRICS.json`.
**Constraint:** behavior-preserving — no change to sound, voices, scales, instrument list, looper
behavior, TonePad, or the carousel. No sample banks, no Learn/community/third-party embeds.
Static, GitHub Pages compatible; Vite build to `dist/` allowed; no new runtime deps without
justification. Branches, one PR per phase, never push to `main` until owner approval.

## Phase 1 — Safety net (this step)
Baseline metrics, lint/format, guards, CSP, debug-flag removal, doc fixes.

Work:
1. Baseline metrics captured → `docs/BASELINE-METRICS.json` (done: JS/CSS bytes, script count,
   `!important` count, looper lines, unguarded `localStorage` reads, axe tags, og:image, CSP,
   portrait lock, prompt/confirm usage).
2. Add ESLint + Prettier config; wire into CI (`npm run lint`, `npm run format:check`) with zero
   errors required.
3. Guard every `localStorage`/`IndexedDB` read with try/catch + schema validation
   (`tonepad-impl.js:72`, `master-clock.js:19`, `app-state.js` already guarded).
4. Add Content-Security-Policy meta (default-src 'self', no unsafe-eval; style/worklet/blob only
   as needed) + Playwright test proving zero CSP violations.
5. Exclude `?debug=1` panel from production build (build-time flag via Vite `define`); remove
   `catch-mode.js` import from `pionier-core-base.js` (dead code, not product UI).
6. Fix docs drift: `index.html` stops linking stub `pionier-layout.css` / `pionier-ambient.css`;
   `ARCHITECTURE.md`, `README.md`, `QUALITY-BASELINE.md` match reality.
7. Add `scripts/doc-drift.mjs` CI test asserting: no `@import` in shipped CSS, script count,
   file existence, budgets. Delete/archive self-graded `PIONIER-10-10-*` scorecards.

Branch: `phase-1-safety-net`. PR #1. Owner approval before Phase 2.

## Phase 2 — Build and architecture
ES modules, bundling, hashed assets, SW generation, dead code removal.

Work:
1. Single ES-module entry; zero classic `<script>` tags except tiny inline boot flag (or none).
   Bundle app JS with esbuild/Vite → hashed filenames.
2. Merge `pionier-core.js` + `pionier-core-base.js` into one canonical module graph.
3. Split `looper.js` (>1600 lines) into recorder / mixer UI / persistence / timing modules,
   none over ~500 lines. Add tests for each split module.
4. Vite build to `dist/`: bundled, minified, hashed JS + CSS. Budget: total JS ≤150 KB gz,
   critical CSS ≤60 KB gz, ≤12 requests to first playable pad, zero `@import` chains.
5. Service worker generated with hashed filenames (cache-first immutable assets, network-first
   HTML); 52-entry manual `?v=` SHELL list generated by `npm run sync:handpan`, not hand-edited.
6. CI script fails on circular imports and on imports of removed modules.
7. Remove remaining dead code (`catch-mode.js`, debug panel references to Kitchen/Bird).

Branch: `phase-2-build-architecture`. PR #2.

## Phase 3 — Accessibility and usability
Knobs, pan focus model, dialogs, landscape, labels.

Work:
1. FX knobs: `role="slider"`, `aria-valuemin/max/now/text`, arrow/Page/Home/End keyboard support.
2. Pan canvas: every pad keyboard-reachable/playable with visible focus + screen-reader name
   (note name + scale degree); keep QWERTY play.
3. Replace `window.prompt`/`window.confirm` (library.js rename/delete) with accessible
   `<dialog>` in-app dialogs.
4. Remove hard portrait lock; usable landscape layout; manifest `orientation` dropped.
5. Replace cryptic "s" FX button with icon + accessible label + tooltip. First-run coach and
   empty states reviewed.
6. Playwright screenshot walkthrough of core tasks (play, change scale, record loop, save,
   export WAV) at 360, 390, 768, 1024, 1440 px; attach to PR.

Branch: `phase-3-a11y-usability`. PR #3.

## Phase 4 — Styling
Tokens, cascade layers, `!important` reduction, responsive matrix.

Work:
1. Single token set (color, spacing, radius, type scale, motion); stylelint rule/script rejects
   hard-coded one-off values in component CSS.
2. Cascade layers + tokens; reduce `!important` by ≥90% (≤~280); each remaining one gets a
   one-line reason comment.
3. Replace every `outline:none`/`outline:0` with visible `:focus-visible`.
4. Add `forced-colors` and `prefers-contrast` styles; script text-contrast check (≥4.5:1),
   print failures.
5. Honor `prefers-reduced-motion` everywhere.
6. Component states (hover/active/focus/disabled) consistent across dock, looper, menus, dialogs;
   keep dark aesthetic; verified by screenshot set.

Branch: `phase-4-styling`. PR #4.

## Phase 5 — Reliability, SEO, CI consolidation, final verification
Work:
1. Global error + unhandledrejection handlers → first-party local-only diagnostics log with
   in-app export button.
2. Boot-state tests (loading/ready/degraded/failed): AudioContext blocked, AudioWorklet
   unsupported, IndexedDB unavailable, storage quota exceeded.
3. Looper memory stress test: 7 layers, bounded memory ceiling.
4. SEO: 1200×630 PNG/JPG og:image; og:url, canonical, twitter:card, theme-color, valid manifest,
   SoftwareApplication JSON-LD, useful noscript fallback, sitemap.xml, robots.txt allow.
5. DevOps: one reusable workflow called by PR + deploy; deploy uses built `dist/` artifact;
   checks gate deploy; remove/justify `expand-lock.yml`; stop committing to main from CI;
   PR artifact with built output + test reports; Dependabot pinned; Actions pinned to commit SHAs;
   least-privilege permissions. Release script bumps version + regenerates SW manifest.
6. Final verification: run all checks, update `docs/BASELINE-METRICS.json` with after numbers,
   produce final report table (category | before | after | evidence | criteria met x/y),
   list owner-gated items and anything not met with reasons.

Branch: `phase-5-reliability-seo-ci`. PR #5.

## Risks
- Playwright suite is slow (~30s/test on this hardware); use focused projects for CI baseline,
  full run only before final merge.
- Real iOS Safari / Android Chrome remain owner-gated (cannot be measured in CI); cap those at 7.
- Bundling ES modules that currently rely on `?v=` query-stamp SW matching must keep SW shell in
  sync with built output (generated SW + cache manifest).
- Removing `pionier-layout.css`/`pionier-ambient.css` links must not break layout (they are stubs,
  but verify with phase8 dock smoke).

## Owner-gated (capped at 7 until verified)
- Physical iOS Safari sign-off (`handpan-app/IOS-SAFARI-CHECKLIST.md`).
- One Android Chrome row in `docs/DEVICE-CHECKLIST.md`.
- Offline reload proof after SW install on phone.
- Sample rights for commercial claims beyond procedural fallback (`docs/AUDIO-LICENSES.md`).
- Perceived sound quality / real-device audio unlock.

## Exit discipline
No category is claimed at 8/10 unless every exit criterion is met AND command output or a file
path proves it. Anything unmet is reported with reasons, not silently lowered.
