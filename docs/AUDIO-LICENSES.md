# Audio Asset Inventory and Licensing

**Last audited:** 2026-10-13  
**Scope:** audio files and generated audio used by Pionier in this repository.

## Current shipped audio

The app ships **no third-party audio files** after the removal in this change. Handpan notes fall back to the existing procedural Web Audio synthesis engine. The ambient player also generates sound procedurally in JavaScript; those generated tones/noise have no external recording author or file license.

Do not add a downloaded sound to the app until its exact source, creator, license terms, commercial-use permission, redistribution permission, and required attribution are recorded here. A website allowing playback/download is not itself a redistribution license.

## Removed sample files — provenance record

The following files were present in the repository before this change. The manifest attributed them to the Haganenote virtual-handpan project. The upstream repository describes samples recorded from handpans made by the project, but the public repository tree does not provide an explicit audio redistribution license. The official virtual instrument page also identifies the samples as Haganenote recordings but does not state a license. Attribution alone does not grant permission to redistribute them, so these files are removed pending written permission or replacement with owner-recorded/cleared recordings.

- Upstream project: https://github.com/haganenote/virtual-handpan
- Official virtual instrument: https://www.haganenote.com/vst/handpan-virtual-instrument.html
- Upstream explanation of recording provenance: https://www.haganenote.com/coding/handpan-vst/

## Release blockers and options

- **Realistic handpan recordings:** not cleared at this audit. Options: (1) provide owner-recorded samples with permission to distribute, (2) provide written permission from the rights holder for the existing Haganenote files, or (3) keep the procedural synth fallback until a cleared sample library is available.
- **Rain, storm, forest/wind, and other beds:** can be procedurally generated without third-party files. If external recordings are later preferred, use CC0/public-domain audio or a license explicitly permitting commercial redistribution inside an app, and retain the license text/receipt and attribution here.
- No purchase or third-party download has been made as part of this change.
