# raw/

Drop the full multi-handpan recording here as `handpan.wav`.

- Keep this folder on the `feat/chop-20-scales` branch only. `main` deploys the website, so the raw file must not be merged into it.
- The chop tool reads it from here: `python3 scripts/chop/chop_handpan.py analyze raw/handpan.wav`
- See `scripts/chop/README.md` for the full steps.
